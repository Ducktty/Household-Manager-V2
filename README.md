# 家当管家 v1 · 演示版

> 手机 App:拍一下产品包装就能识别并加入家里的库存,系统会提前告诉你什么时候该补货、买多少最划算。

## 这是什么

这是一个**纯前端**的家当管理演示 App,实现 SPEC v1.7 里描述的所有 10 个屏幕的核心交互流程,**没有真实 AI 识别**(用 mock 流程模拟),所有数据存在浏览器 `localStorage` 里,刷新不丢。

## 如何运行

### 方法 1:最简单 — 双击 `index.html`

```bash
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

> ⚠️ 拍照、剪贴板等 API 需要 **HTTPS 或 localhost**,纯 `file://` 打开可以跑,但部分功能可能受限。

### 方法 2:本地 HTTP 服务(推荐)

进入项目目录后,任选一种:

```bash
# Python(几乎所有系统都自带)
python3 -m http.server 8080

# Node.js
npx serve -l 8080

# PHP
php -S localhost:8080
```

然后浏览器打开:<http://localhost:8080>

### 方法 3:真机调试(可选)

1. 用 `python3 -m http.server` 在电脑上起服务
2. 找电脑的局域网 IP(如 `192.168.1.100`)
3. 手机连同一 WiFi,浏览器打开 `http://192.168.1.100:8080`
4. 在 Chrome 里按 F12 → 切到手机视图最方便

> 注意:真机要测**真实相机**、**剪贴板自动读取**这些功能,需要 HTTPS(否则浏览器拒绝授权)。可以临时用 `ngrok http 8080` 套一层 HTTPS。

## 核心流程(怎么点)

### A. 主流程(拍照 → Gemini → 粘贴 → 入库)

1. **首页** → 点"📷 拍一下,添加产品"
2. **拍照页** → 点大圆(电脑上会弹文件选择器,选任意一张图模拟)
3. 弹底部抽屉 → 点"✨ 跳转 Gemini 识别"
4. **Gemini 引导页** → Prompt 已自动复制,点"打开 Gemini"会开新窗口
5. 回来后 → 点"已经复制了答案?点这里粘贴"
6. **粘贴页** → 手动输产品名 + 数量 + 价格,点"下一步"
7. 没同款 → 跳**手动输入页**,补分类/周期/单位,保存
8. 跳**详情页**,看到新产品

### B. 简化流程(手动输入)

1. **首页** → 点"不想拍?手动输入产品"
2. 输产品名 → 如果家里已有同款,会显示候选
3. 点候选 → 切到"加进现有库存"模式,只填数量+价格
4. 或者填完整信息,点"保存"

### C. 批量购买计算

1. **详情页** → 点"算一下批量买划不划算"
2. 改 4 个数字 → 点"算一下划算吗"
3. **结果页** → 看 3 种颜色结论(🟢 划算 / 🟡 一般 / 🔴 不建议)
4. 点"加入采购清单"

### D. 采购清单

1. **首页** → 右上角 🛒 图标
2. 看列表,点"移除"或"清空清单"

### E. 长按操作菜单

1. **首页**任意产品卡片 → **长按 0.5 秒**
2. 弹出菜单 → 编辑 / 删除 / 取消

- [ ] 详情页 → 点"算一下批量买划不划算"

- [ ] 结果页点"加入采购清单" → toast + 跳清单页

- [ ] 清单页能看到刚加的产品
- [ ] 点"移除" → 该项消失
- [ ] 点"清空清单" → 弹确认 → 确认后清空

### 持久化

- [ ] 加一个产品 → F5 刷新 → 产品还在
- [ ] 改数量保存 → F5 刷新 → 数量还在
- [ ] 采购清单加一项 → F5 刷新 → 还在

### 编辑 / 删除

- [ ] **长按**首页任意产品卡 0.5 秒 → 弹底部菜单

### 弹窗

- [ ] 任一长按 → 弹菜单;点菜单外区域 → 菜单关闭
- [ ] 删除 / 清空清单 → 弹确认弹窗;点取消 → 不操作

## 已知限制(V1 版范围外)

- 📷 **真实相机调用**:`<input type="file" capture="environment">`,真机 HTTPS 下能调起原生相机;电脑里是文件选择器
- 🤖 **真实 Gemini 识别**:用 `window.open` 跳到 `gemini.google.com`,**不调真实 API**(避免引入 API key)
- 🔍 **剪贴板自动检测**:用 `visibilitychange` 事件 + `navigator.clipboard.readText`,需要用户授权;授权一次后每次切回 App 都会尝试
- 💱 **多货币 / 汇率**:V2 实现,当前仅人民币
- 🖼 **自定义图标**:V2 实现,当前用 emoji 自动猜测
